## Admission order and accounting

Exact bytes only, max 65,536 bytes; UTF-8 strict. Before json.loads, scan outside quoted strings for container nesting (root container depth0; max depth8) and numeric tokens (max32 characters). Escapes only change quote scanning; scanner does not replace JSON grammar. Invalid JSON/duplicate keys/nonfinite constants rejected by decoder. Object keys count as nodes. Root and every value occurrence count, max4096, including repeated alias occurrences; native shared aliases allowed and counted again, ancestor cycles invalid. Types exact dict/list/str/int/bool/None, integers at most32 decimal digits excluding sign; floats/exotic types invalid. Depth includes keys/scalars, root0. Generic strings at most256 ASCII chars. Iterative DFS in insertion/list order, dictionary key immediately before its value; inspect type before invoking behavior. No caller mutation or hooks.

Error priority: bytes type/raw bound/UTF8; lexical depth/numeric cap in encountered order; decoder; native tree preflight DFS; root/common fields in declared order; cases in list order with id,left,right order; unknown supported-profile decision; grammar across ALL cases left then right; component/list caps across ALL cases left then right; compare. Thus late malformed grammar overrides earlier per-component cap; earlier common cap still precedes grammar. Unknown profile gets common admission only, no version grammar/cap parsing.

Root exact profile,synthetic,cases. Profile1..32 matches ASCII [A-Za-z0-9_./-]; synthetic exact true; cases exact list max64. Cases exact id,left,right. id1..32 ASCII [A-Za-z0-9_-], globally unique; versions exact strings of at most256 ASCII chars (empty allowed at common admission, invalid supported grammar). Enabled profile semver-precedence/1. Empty cases complete.

Grammar/caps from PLAN. Grammar validated in bounded ASCII regex with fullmatch; core canonical decimal, prerelease/build ASCII alnum/hyphen dot lists. Numeric prerelease no leading zero; build permits it. Per version cap priority: core components (major/minor/patch) max32 digits; prerelease then build identifier count max16; respective identifiers max64 chars and numeric prerelease max32 digits. Error path names original version field, never invents a JSON component path. Profile limits rather than SemVer validity restrictions.

## Serialization and delivery

Sort JSON object keys, separators comma/colon, ensure_ascii, allow_nan=false, plus LF. 1MiB serialized cap before any delivery; serialize raises controlled output_limit. API reports contain no external paths/errors. CLI INPUT [--output FRESH_FILE], --help fixed ASCII text. Exit0 complete/help,2 invalid/usage,3 unsupported,4 limit,5 transport/delivery. Missing/unreadable input and failed output use fixed stderr JSON {error:input_failure|output_failure|usage|output_limit}; never fall back to successful stdout. Dirty/short/flush/close failure returns5. Failed stream descriptors redirected to devnull to avoid interpreter flush exit120; if both sinks fail exit5 without diagnostic guarantee. File exclusive, empty output is failure, no overwrite. Partial files/delivered bytes possible; no durability/atomicity/race guarantee. Output guard seam explicitly labelled if unreachable by admitted inputs.
