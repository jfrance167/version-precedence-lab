# Security model

Owned synthetic JSON version pairs only. Production code runs no external commands, network, package resolution, downloads or artifact execution. Package existence/authenticity/compatibility/security remain unknown; synthetic=true is a declaration, not provenance proof.

Exact types, raw/lexical/tree/case/string/component bounds and whole-input evaluation reduce exhaustion, coercion, ambiguity and misleading partial results. Serialize before delivery; incomplete admission has no rows. Fixed diagnostics never echo filenames or raw exceptions.

Interpreter/source/filesystem/transport are trusted. No hard RSS/time isolation, concurrent native-input mutation support, hostile filesystem race containment, atomic delivery, durability or real package validation. Owned local paths only; UNC/device-prefixed paths and Windows alternate-stream syntax rejected. Partial output can remain on I/O failure.

Review reproducible defects locally. No public repository/reporting channel or hosted scanner was created. README/VERIFICATION describe tested platform and unavailable checks.
